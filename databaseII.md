Database Schema v2

---

**users** (Unified table for patients, doctors, and admins)
- `user_id` (UUID, Primary Key, Not Null, Default: gen_random_uuid(), Description: Unique identifier for each user)
- `email` (VARCHAR(255), Unique, Not Null, Description: User's email address for login and notifications, encrypted at application level using AES-256)
- `phone_number` (VARCHAR(20), Unique, Not Null, Description: User's phone number in international format (e.g., +250123456789), encrypted at application level using AES-256)
- `password_hash` (VARCHAR(255), Not Null, Description: BCrypt-hashed password for secure authentication, minimum 12 characters enforced at application level)
- `user_type` (ENUM: 'patient', 'doctor', 'admin', Not Null, Description: Defines user role for access control)
- `account_status` (ENUM: 'active', 'inactive', Not Null, Default: 'active', Description: Indicates if account is usable or disabled by admin)
- `created_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), Description: Timestamp of record creation in Central Africa Time (CAT))
- `updated_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), ON UPDATE CURRENT_TIMESTAMP, Description: Timestamp of last update in CAT)

**user_profiles** (Stores essential user information)
- `profile_id` (UUID, Primary Key, Not Null, Default: gen_random_uuid(), Description: Unique identifier for user profile)
- `user_id` (UUID, Foreign Key to users(user_id), Not Null, Unique, ON DELETE CASCADE, Description: Links profile to user, cascades deletion)
- `first_name` (VARCHAR(100), Not Null, Description: User's first name, encrypted at application level using AES-256)
- `last_name` (VARCHAR(100), Not Null, Description: User's last name, encrypted at application level using AES-256)
- `created_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), Description: Timestamp of record creation in CAT)
- `updated_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), ON UPDATE CURRENT_TIMESTAMP, Description: Timestamp of last update in CAT)

**doctors** (Doctor-specific professional details)
- `doctor_id` (UUID, Primary Key, Not Null, Default: gen_random_uuid(), Description: Unique identifier for doctor record)
- `user_id` (UUID, Foreign Key to users(user_id), Not Null, Unique, ON DELETE CASCADE, Description: Links doctor to user account, cascades deletion)
- `medical_license_number` (VARCHAR(50), Unique, Not Null, Description: Doctor's medical license number, encrypted at application level using AES-256)
- `specialty` (VARCHAR(100), Not Null, Description: Doctor's primary specialty, e.g., 'Cardiology', 'Pediatrics')
- `consultation_fee` (DECIMAL(10,2), Not Null, Default: 0.00, Description: Standard fee for a consultation in RWF, e.g., 50000.00)
- `is_active` (BOOLEAN, Not Null, Default: TRUE, Description: Indicates if doctor is available for appointments, toggled by admin)
- `created_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), Description: Timestamp of record creation in CAT)
- `updated_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), ON UPDATE CURRENT_TIMESTAMP, Description: Timestamp of last update in CAT)

**doctor_availability** (Doctor scheduling slots)
- `availability_id` (UUID, Primary Key, Not Null, Default: gen_random_uuid(), Description: Unique identifier for availability slot)
- `doctor_id` (UUID, Foreign Key to doctors(doctor_id), Not Null, ON DELETE CASCADE, Description: Links to doctor, cascades deletion)
- `day_of_week` (INTEGER, Not Null, Check: day_of_week BETWEEN 0 AND 6, Description: Day of week for availability, 0=Sunday, 6=Saturday)
- `start_time` (TIME, Not Null, Description: Start time of availability, e.g., '08:00:00')
- `end_time` (TIME, Not Null, Description: End time of availability, e.g., '16:00:00')
- `slot_duration` (INTEGER, Not Null, Default: 30, Check: slot_duration >= 15, Description: Duration of each appointment slot in minutes, minimum 15 minutes)
- `is_active` (BOOLEAN, Not Null, Default: TRUE, Description: Indicates if availability slot is active)
- `created_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), Description: Timestamp of record creation in CAT)
- `updated_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), ON UPDATE CURRENT_TIMESTAMP, Description: Timestamp of last update in CAT)

**appointments** (Core appointment booking data)
- `appointment_id` (UUID, Primary Key, Not Null, Default: gen_random_uuid(), Description: Unique identifier for appointment)
- `patient_id` (UUID, Foreign Key to users(user_id), Not Null, ON DELETE RESTRICT, Description: Links to patient, prevents deletion if appointments exist)
- `doctor_id` (UUID, Foreign Key to doctors(doctor_id), Not Null, ON DELETE RESTRICT, Description: Links to doctor, prevents deletion if appointments exist)
- `appointment_type` (ENUM: 'consultation', 'follow_up', Not Null, Default: 'consultation', Description: Type of appointment, e.g., initial or follow-up visit)
- `appointment_status` (ENUM: 'scheduled', 'completed', 'cancelled', Not Null, Default: 'scheduled', Description: Current status of appointment)
- `scheduled_date` (DATE, Not Null, Description: Appointment date, e.g., '2025-08-10')
- `scheduled_time` (TIME, Not Null, Description: Appointment start time, e.g., '10:00:00')
- `consultation_fee` (DECIMAL(10,2), Not Null, Default: 0.00, Description: Fee for the appointment in RWF, copied from doctors.consultation_fee)
- `created_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), Description: Timestamp of record creation in CAT)
- `updated_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), ON UPDATE CURRENT_TIMESTAMP, Description: Timestamp of last update in CAT)

**consultations** (Doctor consultation notes)
- `consultation_id` (UUID, Primary Key, Not Null, Default: gen_random_uuid(), Description: Unique identifier for consultation record)
- `appointment_id` (UUID, Foreign Key to appointments(appointment_id), Not Null, Unique, ON DELETE CASCADE, Description: Links to appointment, cascades deletion)
- `patient_id` (UUID, Foreign Key to users(user_id), Not Null, ON DELETE RESTRICT, Description: Links to patient for query efficiency, prevents deletion)
- `doctor_id` (UUID, Foreign Key to doctors(doctor_id), Not Null, ON DELETE RESTRICT, Description: Links to doctor for query efficiency, prevents deletion)
- `notes` (TEXT, Not Null, Description: Doctor's consultation notes, e.g., 'Patient reported cough. Advised rest and fluids.', encrypted at application level using AES-256)
- `created_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), Description: Timestamp of record creation in CAT)
- `updated_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), ON UPDATE CURRENT_TIMESTAMP, Description: Timestamp of last update in CAT)

**invoices** (Patient invoices generated after consultations)
- `invoice_id` (UUID, Primary Key, Not Null, Default: gen_random_uuid(), Description: Unique identifier for invoice)
- `consultation_id` (UUID, Foreign Key to consultations(consultation_id), Not Null, Unique, ON DELETE RESTRICT, Description: Links to consultation, ensures invoice is created post-consultation, prevents deletion)
- `patient_id` (UUID, Foreign Key to users(user_id), Not Null, ON DELETE RESTRICT, Description: Links to patient, prevents deletion)
- `doctor_id` (UUID, Foreign Key to doctors(doctor_id), Not Null, ON DELETE RESTRICT, Description: Links to doctor, prevents deletion)
- `invoice_number` (VARCHAR(20), Unique, Not Null, Description: Auto-generated invoice number, e.g., 'INV-0001')
- `total_amount` (DECIMAL(10,2), Not Null, Default: 0.00, Description: Total invoice amount in RWF, matches appointments.consultation_fee)
- `invoice_status` (ENUM: 'pending', 'paid', 'cancelled', Not Null, Default: 'pending', Description: Invoice payment status, manually updated)
- `invoice_date` (DATE, Not Null, Default: CURRENT_DATE, Description: Date invoice was issued, e.g., '2025-08-04')
- `paid_at` (TIMESTAMP WITH TIME ZONE, Nullable, Description: Timestamp when payment was confirmed, null if unpaid)
- `created_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), Description: Timestamp of record creation in CAT)
- `updated_at` (TIMESTAMP WITH TIME ZONE, Not Null, Default: NOW(), ON UPDATE CURRENT_TIMESTAMP, Description: Timestamp of last update in CAT)
